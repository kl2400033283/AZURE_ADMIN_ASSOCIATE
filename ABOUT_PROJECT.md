PROJECT TITLE : -    Azure Load Balancer Outbound Rules and SNAT Planning

Our project focuses on Azure Load Balancer Outbound Rules and SNAT Planning. The main objective is to understand how backend virtual machines communicate with the internet and how outbound connections can be managed efficiently.When a backend VM needs to communicate with an external service, it creates an outbound connection. Outbound rules define how this traffic is translated and which frontend public IP is used.SNAT stands for Source Network Address Translation. The backend VM has a private IP address, but when it communicates with the Internet, its source address needs to be translated to a public IP.SNAT ports are used to distinguish different outbound connections. When the application creates many simultaneous connections, many SNAT ports are consumed.Therefore, SNAT capacity needs to be planned according to the number of backend instances and the number of outbound connections generated by the application.
